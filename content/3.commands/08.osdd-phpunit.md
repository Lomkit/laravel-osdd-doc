---
title: osdd:phpunit
description: Add one test suite per layer to phpunit.xml.
---

`osdd:phpunit` adds a `<testsuite>` to `phpunit.xml` for each layer that has a `tests/` folder.

```bash
php artisan osdd:phpunit
```

## What it does

1. Reads `phpunit.xml` at the root of the project. It fails if the file or its `<testsuites>` element is missing.
2. Excludes `**/database/migrations` from code coverage, under `<source>`.
3. Adds a test suite named after each layer that has a `tests/` folder and no suite yet.
4. Writes the file back.

Run it again after creating a layer: suites already present are left alone, and so is the coverage exclusion.

:::note
The command only adds suites. Remove the suite of a deleted layer by hand.
:::

## Result

With the `functional/users` and `functional/orders` layers, `phpunit.xml` gets:

```xml [phpunit.xml]
<testsuites>
    <testsuite name="Unit">
        <directory>tests/Unit</directory>
    </testsuite>
    <testsuite name="Feature">
        <directory>tests/Feature</directory>
    </testsuite>
    <testsuite name="functional/users">
        <directory>functional/users/tests</directory>
    </testsuite>
    <testsuite name="functional/orders">
        <directory>functional/orders/tests</directory>
    </testsuite>
</testsuites>
<source>
    <exclude>
        <directory suffix=".php">**/database/migrations</directory>
    </exclude>
</source>
```

## Running a layer's tests

```bash
# One layer
php artisan test --testsuite=functional/orders

# Every suite
php artisan test
```

## Writing tests in a layer

Tests live in the layer's namespace: `Functional\Orders\Tests\Feature` in `tests/Feature/`, `Functional\Orders\Tests\Unit` in `tests/Unit/`.

```bash
php artisan osdd:test PlaceOrderTest --layer=functional/orders
php artisan osdd:test OrderTotalTest --unit --layer=functional/orders
```

:::tip
The `osdd:phpunit` command needs the `dom` PHP extension, a requirement of the package.
:::
