## Project commands

| Command | Description |
|---------|-------------|
| [`osdd:start`](/commands/osdd-start) | Convert a fresh Laravel project to layers |
| [`osdd:layer`](/commands/osdd-layer) | Create a layer and register it in the root `composer.json` |
| [`osdd:seed`](/commands/osdd-seed) | Run the seeders registered by every layer |
| [`osdd:phpunit`](/commands/osdd-phpunit) | Add one test suite per layer to `phpunit.xml` |

## Generators

The class generators of Laravel have an `osdd:*` twin that writes the file inside a layer:

```bash
php artisan osdd:model Order --layer=functional/orders
```
