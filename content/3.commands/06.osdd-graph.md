---
title: osdd:graph
description: Print the graph of the layers and the layers they require.
---

`osdd:graph` prints the `require` edges between layers, read from each layer's `composer.json`. Other packages and `require-dev` entries are left out. Nodes and edges are sorted by name.

```bash
php artisan osdd:graph
```

## Options

| Option | Description |
|--------|-------------|
| `--format` | `mermaid` (default), `dot` or `json`. An unknown format exits with 1. |

## Mermaid

```
graph LR
    functional_orders["functional/orders"]
    functional_users["functional/users"]
    technical_core["technical/core"]
    functional_orders --> functional_users
    functional_users --> technical_core
```

Save it next to your documentation, or paste it in a Markdown file that renders Mermaid, such as a GitHub README:

```bash
php artisan osdd:graph > docs/layers.mmd
```

## DOT

```bash
php artisan osdd:graph --format=dot | dot -Tsvg > layers.svg
```

```
digraph layers {
    rankdir=LR;
    "functional/orders";
    "functional/users";
    "technical/core";
    "functional/orders" -> "functional/users";
    "functional/users" -> "technical/core";
}
```

Render it with [Graphviz](https://graphviz.org).

## JSON

```bash
php artisan osdd:graph --format=json
```

```json
{
    "nodes": ["functional/orders", "functional/users", "technical/core"],
    "edges": [
        {"from": "functional/orders", "to": "functional/users"},
        {"from": "functional/users", "to": "technical/core"}
    ]
}
```

:::tip
`osdd:graph` shows what the layers declare. [`osdd:check`](/commands/osdd-check) checks that the code matches it.
:::
