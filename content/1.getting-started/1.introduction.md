Laravel OSDD (Open Source Driven Development) splits a Laravel application into **layers**. A layer is a Composer package that lives in your repository, with its own models, migrations, seeders, tests, routes and service provider.

The default `app/`, `database/` and `config/` folders give way to two folders at the root of the project:

- `functional/` holds the business domains: `users`, `orders`, `billing`.
- `technical/` holds the shared infrastructure: the OSDD configuration, authentication wiring, observability.

## Why layers

A fresh Laravel application keeps every domain in the same folders:

```
app/
  Models/User.php
  Models/Order.php
  Models/Invoice.php
  Http/Controllers/UserController.php
  Http/Controllers/OrderController.php
  ...
```

Nothing separates billing from orders. Migrations, seeders and tests are global, and a change in one domain means browsing folders shared with every other one.

With OSDD, each domain owns its package:

```
functional/
  users/
    composer.json        ← package "functional/users"
    src/
      Models/User.php
      Providers/UsersServiceProvider.php
    database/
      migrations/
      factories/
      seeders/
    tests/
  orders/
    composer.json        ← package "functional/orders"
    src/
      Models/Order.php
      Providers/OrdersServiceProvider.php
    database/
    tests/
technical/
  osdd/
    composer.json        ← package "technical/osdd"
    config/osdd.php
    src/
      Providers/OsddServiceProvider.php
```

A layer declares the layers it depends on in its `composer.json`, so the dependencies between domains stay visible. Each layer has its own test suite, its own seeders and its own configuration.

:::note
Layers share the same Composer autoloader. OSDD does not block a layer from using a class of a layer it does not require: the boundaries are a convention you keep, written down in each `composer.json`.
:::

## What the package gives you

- [`osdd:start`](/commands/osdd-start) converts a fresh Laravel project to layers.
- [`osdd:layer`](/commands/osdd-layer) creates a layer and registers it in your root `composer.json`.
- The [`osdd:*` generators](/commands/make-commands) write classes inside the layer you pick, like their `make:*` twins.
- [`osdd:seed`](/commands/osdd-seed) runs the seeders every layer registers.
- [`osdd:phpunit`](/commands/osdd-phpunit) adds one test suite per layer to `phpunit.xml`.
- [`LayerServiceProvider`](/layers/service-provider) loads a layer's migrations, seeders, routes and configuration.
- A [Laravel Boost](/integrations/laravel-boost) skill teaches your coding agent where files go.

## Requirements

- PHP **8.3** or higher
- Laravel **13.0** or higher
- The `dom` PHP extension
