## Requirements

- PHP **8.3** or higher
- Laravel **13.0** or higher
- The `dom` PHP extension

:::note
Laravel 12 applications stay on Laravel OSDD 2.x. See the [upgrade guide](/getting-started/upgrade-guide) to move to 3.0.
:::

## Installing Laravel OSDD

Install the package with:

```bash
composer require lomkit/laravel-osdd
```

Laravel discovers the package's service provider, `Lomkit\Osdd\OsddServiceProvider`. There is nothing to register.

Then pick your path:

- **Fresh project**: run [`osdd:start`](/commands/osdd-start) to convert the project to layers in one command. The [quick start](/getting-started/quick-start) walks through it.
- **Existing project**: keep your code where it is and add layers one at a time with [`osdd:layer`](/commands/osdd-layer).

:::warning
`osdd:start` deletes `app/`, `database/` and `config/`. Never run it on a project with code you want to keep.
:::

## Configuration

The package reads the folders that hold layers from the `osdd.layers.paths` key:

```php [config/osdd.php]
return [
    'layers' => [
        'paths' => [
            'functional' => base_path('functional'),
            'technical' => base_path('technical'),
        ],
    ],
];
```

After `osdd:start` there is no root `config/` folder: the `technical/osdd` layer holds this file and overrides the package defaults. See [Configuration](/layers/configuration) to add your own folders.
