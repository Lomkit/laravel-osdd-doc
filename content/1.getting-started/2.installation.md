## Requirements

- PHP **8.3** or higher
- Laravel **13.0** or higher
- The `dom` PHP extension

Optional:

- [Livewire](/integrations/livewire) **4**, to register and generate Livewire components in layers.
- [Filament](/integrations/filament) **5**, to discover the Filament resources, pages and widgets of every layer.

OSDD works without them: the code that uses them only runs when they are installed.

:::note
Laravel 12 applications stay on Laravel OSDD 2.x. See the [upgrade guide](/getting-started/upgrade-guide) to move to 3.0.
:::

## Installing Laravel OSDD

Install the package with:

```bash
composer require lomkit/laravel-osdd
```

Laravel discovers the package's service provider, `Lomkit\Osdd\OsddServiceProvider`. There is nothing to register.

Then pick your path:

- **Fresh project**: run [`osdd:start`](/commands/osdd-start) to convert the project to layers in one command. The [quick start](/getting-started/quick-start) walks through it.
- **Existing project**: keep your code where it is and add layers one at a time with [`osdd:layer`](/commands/osdd-layer).

:::warning
`osdd:start` deletes `app/` and `config/`, and empties `database/` except the SQLite database. It asks for confirmation first. Never run it on a project with code you want to keep.
:::

## Configuration

The package reads its settings from the `osdd` config key:

```php [technical/osdd/config/osdd.php]
return [
    'layers' => [
        'paths' => [
            'functional' => base_path('functional'),
            'technical'  => base_path('technical'),
        ],
    ],

    'boundaries' => [
        'ignore' => [],
    ],

    'events' => [
        'discover' => false,
    ],
];
```

The config file is not published: after `osdd:start` there is no root `config/` folder. The `technical/osdd` layer holds this file and overrides the package defaults with it. See [Configuration](/layers/configuration) for every key.
