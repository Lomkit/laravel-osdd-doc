## Requirements

- PHP **8.3** or higher
- Laravel **13.0** or higher
- The `dom` PHP extension

Optional:

- [Livewire](/integrations/livewire) **4**, to register and generate Livewire components in layers.
- [Filament](/integrations/filament) **5**, to discover the Filament resources, pages and widgets of every layer.

OSDD works without them: the code that uses them only runs when they are installed.

:::note
Laravel 12 applications stay on Laravel OSDD 2.x. See the [upgrade guide](/upgrade/from-2x) to move to 3.0.
:::

## Install the package

```bash
composer require lomkit/laravel-osdd
```

Laravel discovers the package's service provider, `Lomkit\Osdd\OsddServiceProvider`. There is nothing to register and nothing to publish.

  ---

  :::
::

:::warning
`osdd:start` deletes `app/` and `config/`, and empties `database/` except the SQLite database. It asks for confirmation first. Never run it on a project with code you want to keep.
:::

## Configure

The defaults work as they are: layers live in `functional/` and `technical/`. To change a setting, see the [configuration reference](/api-reference/configuration).

## Teach your coding agent

The package ships a [Laravel Boost](/integrations/laravel-boost) skill. With Boost installed, your agent creates layers and generates code inside them instead of writing to `app/`.
