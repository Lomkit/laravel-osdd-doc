title: LayersCollection
description: Discover and inspect the layers of the project from your own code.
---

The commands find layers through three classes. Use them in your own commands or tooling.

## LayersCollection

`Lomkit\Osdd\Layers\LayersCollection` extends `Illuminate\Support\Collection`. Each item is a [`Layer`](#layer).

### fromConfig()

```php
public static function fromConfig(): LayersCollection
```

Discovers the layers of every folder in `osdd.layers.paths`.

```php
use Lomkit\Osdd\Layers\LayersCollection;

foreach (LayersCollection::fromConfig() as $layer) {
    echo $layer->manifest->name(); // functional/orders
}
```

### discover()

```php
public static function discover(string ...$paths): LayersCollection
```

Discovers the layers of the given folders, without reading the config.

```php
$layers = LayersCollection::discover(base_path('functional'), base_path('technical'));
```

### Discovery rules

For each folder:

1. A sub-folder whose `composer.json` has `"type": "layer"` is a layer.
2. Any other sub-folder is scanned the same way.

A folder that does not exist is ignored.

## Layer

`Lomkit\Osdd\Layers\Layer` is one discovered layer.

| Property | Type | Description |
|----------|------|-------------|
| `$path` | `string` | Absolute path of the layer folder |
| `$manifest` | `LayerManifest` | The layer's parsed `composer.json` |

| Method | Description |
|--------|-------------|
| `Layer::fromDirectory(SplFileInfo $directory)` | Builds a layer from a folder |
| `Layer::isValidLayerDirectory(SplFileInfo $directory)` | `true` when the folder's `composer.json` has `"type": "layer"` |

## LayerManifest

`Lomkit\Osdd\Layers\LayerManifest` reads a layer's `composer.json`.

| Method | Returns | Example |
|--------|---------|---------|
| `name()` | `string` | `functional/orders` |
| `type()` | `string` | `layer` |
| `vendor()` | `string` | `functional` |
| `package()` | `string` | `orders` |
| `isLayer()` | `bool` | `true` |
| `rootNamespace()` | `string` | `Functional\Orders\` |
| `srcPath(string $layerPath)` | `string` | `/var/www/functional/orders/src` |

`rootNamespace()` and `srcPath()` read the first `psr-4` entry of the layer's `composer.json`.

```php
use Lomkit\Osdd\Layers\LayersCollection;

$layer = LayersCollection::fromConfig()
    ->first(fn ($layer) => $layer->manifest->name() === 'functional/orders');

$layer->manifest->rootNamespace();         // Functional\Orders\
$layer->manifest->srcPath($layer->path);   // /var/www/functional/orders/src
```
