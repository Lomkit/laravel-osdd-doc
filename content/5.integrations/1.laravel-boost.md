Laravel OSDD ships a [Laravel Boost](https://github.com/laravel/boost) skill. With it, a coding agent knows that an OSDD project has no `app/` folder: it creates layers with `osdd:layer`, generates classes with the `osdd:*` commands and `--layer`, and wires seeders, config and routes through the layer's provider.

## Installation

Install Boost in your project, then pick `lomkit/laravel-osdd` when it lists the packages that ship guidelines and skills:

```bash
composer require laravel/boost --dev
php artisan boost:install
```

Boost copies the `laravel-osdd` skill into your agent's skills folder and records the package in `boost.json`:

```json [boost.json]
{
    "packages": [
        "lomkit/laravel-osdd"
    ]
}
```

## Keeping it up to date

The skill follows the package version. Refresh it after each update of `lomkit/laravel-osdd`:

```bash
php artisan boost:update
```

:::note
Coming from `xefi/laravel-osdd`? Replace the package name in `boost.json` before you run `boost:update`, or Boost removes the skill. See the [upgrade guide](/getting-started/upgrade-guide#laravel-boost).
:::

## What the skill covers

- Detecting an OSDD project and finding the layer that owns a concept.
- Never writing to `app/`, `database/` or the root `config/`, and never running a bare `make:*` command.
- Creating a layer, and generating code inside it with `--layer`.
- Wiring migrations, seeders, config overrides and routes in the layer's `LayerServiceProvider`.
- Running `osdd:seed` and `osdd:phpunit` after a change.
