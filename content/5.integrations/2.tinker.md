---
title: Tinker
description: Use the short name of any layer class in Tinker.
---

Inside `php artisan tinker`, OSDD resolves layer classes by their short name. Type `Order` instead of `Functional\Orders\Models\Order`:

```php
> Order::count()
= 50

> Functional\Orders\Models\Order::count()
= 50
```

When Tinker starts, OSDD scans the source directory of every layer (`src/`), adds the layers' root namespaces to `tinker.alias`, and registers an autoloader that maps each short class name to its full name.

The aliases only exist inside Tinker. Application code keeps its `use` statements.

:::warning
When two layers define a class with the same short name, such as `Functional\Users\Models\User` and `Functional\Admin\Models\User`, the layer that comes first by name wins. Use the full name to pick the other one.
:::
