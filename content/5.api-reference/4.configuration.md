The package reads the `osdd` config key:

```php [technical/osdd/config/osdd.php]
return [
    'layers' => [
        'paths' => [
            'functional' => base_path('functional'),
            'technical'  => base_path('technical'),
        ],
    ],

    'boundaries' => [
        'ignore' => [],
    ],

    'events' => [
        'discover' => false,
    ],
];
```

| Key | Default | Description |
|-----|---------|-------------|
| `layers.paths.functional` | `base_path('functional')` | [Bucket](/concepts/buckets) of the business layers |
| `layers.paths.technical` | `base_path('technical')` | Bucket of the infrastructure layers. Add more keys to add buckets. |
| `boundaries.ignore` | `[]` | Class prefixes and layer pairs that [`osdd:check`](/commands/osdd-check) does not report, see [Ignoring a dependency](/concepts/boundaries#ignoring-a-dependency) |
| `events.discover` | `false` | Discover the listeners of every layer, see [Events](/guides/events). Must be a boolean. |

The key of each path is also the vendor of the layers created in it: `osdd:layer functional/orders` creates the layer in the `functional` path. See [Buckets](/concepts/buckets).

## Where to set it

`osdd:start` deletes the root `config/` folder and creates the `technical/osdd` layer instead. Its provider overrides the package defaults with the layer's file:

```php [technical/osdd/src/Providers/OsddServiceProvider.php]
<?php

namespace Technical\Osdd\Providers;

use Lomkit\Osdd\LayerServiceProvider;
use Lomkit\Osdd\Seeders\LayersSeeder;

class OsddServiceProvider extends LayerServiceProvider
{
    public function boot(): void
    {
        if ($this->app->runningInConsole()) {
            $this->loadMigrationsFrom(__DIR__ . '/../../database/migrations');
        }
    }

    public function register(): void
    {
        $this->overrideConfigFrom(__DIR__ . '/../../config/osdd.php', 'osdd');

        $this->app->bind('DatabaseSeeder', LayersSeeder::class);
    }
}
```

The provider also loads the cache and jobs migrations of the skeleton, and binds [`LayersSeeder`](/api-reference/seeder-registry#layersseeder) as the default seeder of `db:seed`.

:::note
`Technical\Osdd\Providers\OsddServiceProvider` belongs to your application. The package's own provider is `Lomkit\Osdd\OsddServiceProvider`.
:::

The package does not publish its config file: `vendor:publish` has nothing to copy for `Lomkit\Osdd\OsddServiceProvider`. Change the settings in `technical/osdd/config/osdd.php`. A project that keeps its root `config/` folder can also create `config/osdd.php` by hand.
